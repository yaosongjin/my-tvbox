# ---- pinned.txt：手工钉死的直播源（永远排在同一频道的第 1 条） ----
#
# 格式：频道名,地址      （逗号分隔；空行和 # 开头的行会被忽略）
# 频道名随便写，会被自动归一化：CCTV-3 / CCTV3 / 中央电视台综艺频道 都认作 CCTV3
# 也可以只写地址，会自动从地址里猜台号（地址里要有 cctv3 这类字样）
#
# 用法：把家里实际能正常看、且不插广告的地址填进来。
#       这里填过的频道，自动抓来的源只会排在"线路2 / 线路3"。
#
# 示例（把 http://... 换成你自己的地址，行首加 # 表示暂不启用）：
#
# CCTV3,http://192.168.1.1:8080/tsfile/live/0003_1.m3u8
# CCTV1,http://192.168.1.1:8080/tsfile/live/0001_1.m3u8
# 湖南卫视,http://192.168.1.1:8080/tsfile/live/0100_1.m3u8
